# Versão 1.0 - Portfólio

Data de referência: 28 de outubro de 2026.

Esta versão registra o estado público do projeto acadêmico **Soja em fluxo** após a apresentação da equipe.

## Destaques

- site responsivo com visão das bases, metodologia, cálculos e limitações;
- pipeline Python para agregar exportações mensais por NCM e destino;
- suporte aos cabeçalhos oficiais `CO_ANO`, `CO_MES`, `CO_NCM`, `CO_PAIS`, `KG_LIQUIDO` e `VL_FOB` do Comex Stat;
- catálogo de documentos com autoria, fontes, versão e situação de validação;
- separação explícita entre dados observados, demonstrações didáticas, resultados não validados e modelos não executados;
- licença MIT para o código e aviso específico para documentos, dados, marcas e materiais de terceiros;
- registro de propostas futuras, incluindo análise preditiva com aprendizado de máquina, ainda não implementada nem validada.

## Limitações registradas

Os cenários, a alocação portuária e parte dos indicadores permanecem como estruturas projetadas, sem execução empírica completa. Valores ilustrativos não representam previsão de mercado, recomendação comercial ou garantia de rentabilidade.
